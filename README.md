# Shree Narayani Traders

The company website, served by GitHub Pages from `main` at
[shreenarayanitraders.com](https://shreenarayanitraders.com).

## Pages

| Path | What it is |
|---|---|
| `index.html` | Landing page. |
| `search.html` | Product search across the full catalogue. |
| `catalogues.html` | Company-wise product catalogues. |
| `near-expiry/` | Near-expiry offers catalogue and its admin. **Not linked from anywhere on this site** — see below. |

## Near-expiry

`near-expiry/` is a self-contained app with its own
[README](near-expiry/README.md). Its Excel importer matches distributor product names against
the SNT master; that matcher and the safeguards around it are tested with
`node --test "near-expiry/tests/*.test.js"` — no dependencies to install. Run it after
touching `near-expiry/matching.js` or `near-expiry/sheet.js`. It is shared by link with trade contacts rather than
advertised: nothing on this site links to it, both its pages carry `noindex`, and
`robots.txt` disallows the folder. That keeps it out of search results — it is not an
access control, and the catalogue stays readable to anyone holding the URL. Its admin page
is protected by Supabase Auth.

It reads `Photos/` as a fallback for products it has no photo of its own for, through
`near-expiry/photo-map.json`. Regenerate that map whenever `data.js` is rebuilt:

```sh
python3 tools/build-photo-map.py
```

## Data

- `data.js` — the catalogue, plus `PHOTO_MAP`. **Generated by `convert.py`; do not edit by
  hand.** `convert.py` itself is kept outside this repository.
- `Photos/` — product pack shots, named after the product. `search.html` and the near-expiry
  catalogue both read them; nothing in this repository writes to the folder.
- `logos/`, `logo.png` — company marks.
- `CNAME` — the custom domain. Only one repository can hold it.
